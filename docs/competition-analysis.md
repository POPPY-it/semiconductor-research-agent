# 竞品分析：同类开源项目功能对比与差距清单

> 对标对象：GPT-Researcher（28.4k★，自动研究报告生成）、Dify / RAGFlow / FastGPT（企业级知识库平台）。

## 1. 与 GPT-Researcher 对比（最直接同类）

| 能力 | GPT-Researcher | 我们（现状） |
|---|---|---|
| 自动研究报告生成 | ✅ 深度研究模式，长报告 | ✅ 三 Agent + 质检 + 修订 |
| 引用溯源 | ✅ 检索结果带来源 | ✅ 数字带链接 + 质检核查 |
| 多检索源 | ✅ 数十种（Google/arXiv/新闻 API/本地文档） | ⚠️ 3 个源（SEC + 2 RSS） |
| 文档解析 | ✅ PDF/网页 | ⚠️ 仅 HTML 段落提取 |
| 报告可视化 | ✅ 图表生成 | ❌ 纯文本 |
| 多轮追问 | ✅ | ❌ 问答无历史上下文 |
| 数据自采管道 | ❌（靠第三方搜索 API） | ✅ 自建采集+SQLite（我们的差异化） |
| 质检环节 | ❌ 无独立质检 Agent | ✅（我们的差异化） |

## 2. 与 Dify / RAGFlow 对比（企业级知识库平台）

| 能力 | Dify / RAGFlow | 我们（现状） |
|---|---|---|
| 文档解析 | ✅ PDF/Word/Excel/OCR/表格深度解析 | ❌ 无 PDF/Word |
| 知识库管理 | ✅ 上传/删除/分块策略配置/重建索引 UI | ❌ 无上传入口 |
| 引用精确定位 | ✅ 溯源到原文段落 | ⚠️ 文档级 |
| 多轮对话 | ✅ 对话应用+历史 | ❌ |
| 评测体系 | ✅ RAGAS 回归评测 | ⚠️ 仅离线评测脚本 |
| 多用户/权限 | ✅ 多租户/成员/权限 | ⚠️ 单用户 token |
| 定时任务管理 | ✅ 工作流定时+UI | ⚠️ APScheduler 无 UI |
| 可观测 | ✅ 追踪面板 | ⚠️ 指标端点无面板 |

## 3. 我们的差异化（竞品没有的）

1. **自建数据采集管道**：SEC 官方 API + 合规限速 + 去重入库——竞品靠第三方搜索 API，数据不可审计
2. **质检 Agent + 交付策略**：独立事实质检 + caveat/reject 策略——GPT-Researcher 无质检环节
3. **垂直行业模板**：日报/周报/深度三套结构模板

## 4. 差距整改路线图（按"生产级可用"优先级）

| 优先级 | 差距 | 状态 |
|---|---|---|
| P0 | 正文提取升级（trafilatura）+ 数据重抓 | ✅ 已落地（IT之家正文 7 篇入库；GoogleNews 依赖的代理不稳定，已降级为可选源） |
| P0 | 文档上传+PDF解析入库+重建索引（API+UI） | ✅ 已落地（POST /api/v1/documents + 前端拖拽上传 + 索引互斥重建） |
| P1 | 多轮对话（问答历史+追问上下文） | 下一轮 |
| P1 | 报告自动图表（CodeAgent 生成 PNG 内嵌报告） | 下一轮 |
| P1 | 更多直连数据源（新浪科技已接入但低产；需继续找高产直连源） | 持续 |
| P2 | RAGAS 评测回归 | 后续 |
| P2 | 定时任务管理 UI | 后续 |
| P2 | 引用定位到段落 | 后续 |

| 源 | 状态 | 说明 |
|---|---|---|
| SEC EDGAR | ✅ 32 篇财报全文 | 官方 API，稳定 |
