# 竞品分析：对标清单与差距整改（2026-08 更新版）

> 用途：体验"比我们强很多"的对标项目，明确差距与深耕方向（秋招 Agent 岗叙事）。
> 体验顺序建议：千问财经分析（免费/中文/最直接）→ Gemini/ChatGPT Deep Research（推理链天花板）→ STORM（开源/研究 Agent 学术路线）→ GPT-Researcher（开源/工程纵深）。

## 1. 第一梯队：产品级（免费/低成本可体验）

| 竞品 | 类型 | 体验入口 | 强在哪 | 我们的差距 |
|---|---|---|---|---|
| **千问「深度研究 / 财经分析」**（阿里） | 产品（免费） | chat.qwen.ai 网页/App | 接入 1.3 万支 A 股实时行情 + 百万财报语料，一键生成机构级研报；多轮追问、图表、来源标注 | 数据底座（实时行情/百万财报 vs 静态知识库+搜索网关）；研报质量；产品化 |
| **同花顺问财** | 产品（免费） | App/网页 | A 股全市场对话式投研、数据全、图表丰富 | 同上：数据覆盖面与交互成熟度 |
| **Gemini Deep Research / ChatGPT Deep Research** | 产品（付费） | Gemini/ChatGPT | 通用深度研究天花板：多源交叉、推理链可见、段落级引用 | 推理链展示（我们只有 SSE 步骤流）、引用粒度、多源广度 |

## 2. 第二梯队：开源高星（本地可跑、可读代码学技术栈）

| 竞品 | stars | 仓库 | 强在哪 | 我们的差距 |
|---|---|---|---|---|
| **Stanford STORM** | ~12k | github.com/stanford-oval/storm | 长文研究报告生成（Agentic RAG）：**多视角提问→大纲→分节检索写作→段落级引用**（coarse-to-fine） | 我们的 planner 是规则模板；引用是"数字后带链接"启发式，非段落级 |
| **GPT-Researcher** | 28.6k | github.com/assafelovic/gpt-researcher | 10+ 检索器插件体系（Google/arXiv/新闻/PDF…）、缓存与成本控制、深度研究模式 | 检索源广度、文档解析、成本控制工程化 |

## 3. 第三梯队：机构级（了解天花板，无需体验）

- **BloombergGPT**（彭博，500 亿参数金融 LLM，3,630 亿金融语料）
- **Morgan Stanley AskResearchGPT / 各大卖方 AI 研报**
- **Wind / iFinD 终端 AI 研报**
> 面试口径：能说出"机构产品在哪几层碾压我们"即可，不需要真用过。

## 4. 体验时看 3 个点（把差距转成技术点）

1. **推理链可见性**：Deep Research 展示完整思考→检索→写作过程；我们只有 SSE 步骤流（无思考中间态）。
2. **引用质量**：STORM/Deep Research 是段落级多源对照；我们是"数字后 120 字符内是否有链接"（启发式）。
3. **数据覆盖**：千问有实时行情+百万财报；我们是 6 源静态语料 + 搜索网关（实时但有成本）。

## 5. 深耕建议（体验后挑 1-2 个做深，不要全做）

| 技术点 | 对标 | 说明 |
|---|---|---|
| **多视角大纲规划**（升级 planner） | STORM | LLM 生成"读者视角问题"→ 按问题检索 → 大纲 → 分节写作；替换规则模板 |
| **段落级引用 + 引用密度评测** | STORM / Deep Research | 引用粒度从"数字后带链接"升级为"每段多源对照"；harness 加引用密度指标 |
| **数据底座扩展** | 千问 | 接行情/财报实时 API 或深耕搜索网关双通道（注意成本） |

## 6. 我们相对竞品的差异化（保持）

- **评测闭环**：24 条任务集 + 轨迹回放 + 可复现指标（成功率/无引用率/成本）——STORM/GPT-Researcher 没有同等口径的 Agent 级评测
- **质检 + 交付策略**：事实质检 Agent + caveat/reject——GPT-Researcher 无质检环节
- **垂直模板 + 合规边界**：研投/医学模板带免责声明与合规约束
