口径：pipeline.generate 全流程（研究 Agent + 质检 + 修订 ≤2 轮），不含索引构建（一次性）。

## 2. 失败率与质检

| 指标 | 值 | 说明 |
|---|---|---|
| 失败率 | **4.2%**（1/24） | t14 触发 token 预算熔断（399 万/400 万字符）——**设计行为**：熔断器防止成本失控，任务被干净标记 error 而非挂死 |
| 质检通过率 | 65%（15/23） | 未通过者按 caveat 策略带警示横幅交付（可复现：轨迹里可回放每条 issue） |

## 3. 单篇成本估算

| 项 | 值 |
|---|---|
| 预算字符（均值） | 1,893,584 字符/篇（P50 1,916,994 / P95 3,380,348） |
| 估算 token | ≈151 万（中文为主，按 0.8 token/字符的保守换算） |
| 单价（DeepSeek v4-flash，2026-08 官方价） | 输入缓存未命中 1.5 元/M tokens；输出 4.5 元/M tokens；空闲时段半价 |
| **单篇成本（高峰、按输入:输出=9:1）** | ≈2.7 元/篇 |
| **单篇成本（空闲时段）** | ≈1.4 元/篇 |
| 全量 24 条评测集 | ≈40~65 元 |

> 口径说明（诚实标注）：
> - 预算字符是 BudgetedModel 的**熔断估算**（按消息字符串长累计），高于实际计费 token 数（实际含前缀缓存命中，计费更低）——本表是**上限估算**；
> - 学术调研类（survey）显著高于均值（t13 预算 263 万字符），财报/图谱类更低（t06 66 万）；
> - 未计入实时搜索网关 credits（Serper/Tavily 按次计费，约 1 credit/次，测试级用量可忽略）。

## 4. 结论与面试口径

- **"2 小时 → 15 分钟"已从 PLAN 删净**，替换为实测：**P50 ≈ 5 分钟/篇，P95 ≈ 8 分钟，失败率 4.2%，单篇 ≤3 元**；
- 面试话术：单篇成本（≤3 元）和时延（P50 5 分钟）是**可复现数字**，且失败是"熔断保护"而非"进程崩溃"——每条失败都能指到轨迹；
- 已知成本优化空间（诚实列出）：survey 类任务信息密度低、token 烧得快（t14 熔断即此类），下一步可做"检索聚焦 + 输出压缩"。
