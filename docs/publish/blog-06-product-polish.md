# 技术博客⑥：从"能跑"到"好用"——多轮对话、图表与学术调研的三个关键补全

> 系列第六篇。产品上线后，用户会立刻问两个问题：**"能追问吗？"** 和 **"报告能不能更好看？"**
> 这一篇讲我补上的三个关键能力，以及一次产品方向的调整。

## 先说方向调整：从"行业研报"到"研究助手"

做完第一版，我拿它和 GPT-Researcher 对标，发现一个尴尬的事实：光靠"半导体行业日报"，产品感太弱，新闻数据也受反爬和代理限制。于是我做了个决定——**加学术调研方向**，因为这是市场验证过的需求（Elicit、Consensus、Deep Research 都在抢科研用户）。

数据质量立刻改观：arXiv 官方 API 免费稳定、论文质量高、引用可溯源。一次采集就入了 49 篇论文，知识库翻倍。

## 1. 多轮对话：把"问答"变成"对话"

原来的问答是一问一答，没有记忆。用户问"台积电营收多少？"接着"那 ASML 呢？"——它不知道"那"指代什么。

改造：**会话存储 + 历史上下文**。每次提问携带最近几轮 Q/A 作为上下文，指令里明确要求"结合历史理解指代"。实测：

> 问：台积电 2026 年 7 月营收是多少？
> 答：4,675.8 亿新台币，同比 +44.7%…
> 追问：那 ASML 第二季度呢？
> 答：ASML Q2 净销售额 93 亿欧元、净利润 29 亿欧元，环比 +5.7%…

指代消解正确。这一条是"产品感"最直接的分水岭。

## 2. 报告图表：让 CodeAgent 顺手画图

CodeAgent 的核心理念是"让模型写代码"，那就把 matplotlib 也变成一个工具。研究 Agent 发现报告里有可量化对比数据时，调用 `generate_chart` 生成 PNG，报告里嵌入 `![](/charts/xxx.png)`。

实测一份周报自动生成了 3 张图：营收对比柱状图、环比增速图、全年预估图。报告从"一屏文字"变成"有图有真相"。

踩坑：图表目录和静态挂载目录不一致，图片全部 404。**生成路径、存储路径、服务路径三处必须统一**，这是文件类功能的经典 bug。

## 3. 学术调研：从数据到引文

除了 arXiv，我还加了 **Semantic Scholar**（返回论文被引次数），让调研报告能标注"高被引经典工作" vs "新提出方法"。学术调研模板的产出长这样：

> - SynAct：自适应闭环 LLM 推理-行动智能体，芯片综合优化 WNS 降至 27%
> - GateTruth：变异测试审计 RTL 基准的 Goodhart 效应
> 参考文献：[n] 标题（作者，年份）链接

**这份调研报告是质检 Agent 第一次给出 passed:true**——学术文献的引用规范天然比新闻数字好验证。

## 4. 顺带补上的：文档上传

用户自己的 PDF/报告，拖进去就解析入库、重建索引、立即可检索。这让产品从"只有公开数据"变成"能接私有数据"——企业场景的门槛。

## 反思：功能补齐靠的是"竞品清单"

这些功能不是拍脑袋想的，是列了 GPT-Researcher / Dify / RAGFlow 的对比表，把"他们有我没有"的项按优先级排出来逐条补。**做产品最怕的不是缺功能，是不知道缺什么。**
