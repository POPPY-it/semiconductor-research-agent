# 博客发布与仓库公开指南

> 目标：让面试官能点开两个公开链接——① 你的技术博客系列 ② 你的 GitHub 项目仓库。

## 一、发布博客①到掘金（约 5 分钟）

1. 浏览器打开 https://juejin.cn ，登录你的账号（无账号先注册，微信/手机号均可）
2. 右上角「写文章」→ 进入 Markdown 编辑器
3. 全选粘贴 `docs/publish/blog-01-juejin.md` 的正文（**不要**包含开头 `---` frontmatter 块，掘金对它的支持不稳定）
4. 手动填写：
   - **标题**：`1800 行读懂一个 Agent 引擎：smolagents 内核剖析`
   - **摘要**：`精读 HuggingFace smolagents 核心源码：主循环、错误分级、记忆模型与 CodeAgent 沙箱设计，以及基于它做产品化改造的 4 个挂载点。`
   - **标签**：`AI Agent`、`LLM`、`开源`、`Python`
   - **封面**：可选掘金默认封面，或后续用项目截图（Agent 执行流程图）替换
5. 发布时选择「公开」
6. 拿到文章 URL 后，回填到本仓库 `docs/publish/README.md` 的链接清单

> 备选：知乎（zhuanlan.zhihu.com/write 支持 Markdown 粘贴，同样内容可直接发一份）。
> 建议主发掘金，知乎/CSDN 转发，扩大曝光。

## 二、把项目仓库推到 GitHub（约 3 分钟）

1. 浏览器打开 https://github.com/new
2. 仓库名建议：`semiconductor-research-agent`；选择 **Private 或 Public 均可**（面试展示建议先 Private，秋招投递时再转 Public 或按需给链接）；**不要**勾选初始化 README
3. 创建后拿到仓库 URL（形如 `https://github.com/<你的用户名>/semiconductor-research-agent.git`），然后二选一：
   - 告诉我 URL，我帮你执行推送
   - 或自己在本机执行：
     ```powershell
     cd D:\qwen3.6\semiconductor-agent
     git remote add origin https://github.com/<你的用户名>/semiconductor-research-agent.git
     git push -u origin main
     ```
   （本机已有 GitHub 凭据/SSH 密钥，应能免密或弹窗登录）

4. 推送成功后，回填博客文末的仓库链接（把 `> 项目代码见 GitHub 仓库` 补全为真实 URL）
