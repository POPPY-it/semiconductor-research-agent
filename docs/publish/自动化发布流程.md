## 关键步骤备忘（第二篇修正版）

1. **扫码登录**（仅首次）：`juejin_qr_login.py`；登录态保留在 `qr-profile\`，后续发布免扫码
2. **建草稿**：`juejin_publish_create.py <标题> <md路径>` → `editor/drafts/new` → 标题 input + CodeMirror setValue → 自动保存 → 输出草稿 URL
3. **发布弹窗**：点「发布」；分类默认继承上一次的选择（`item active` 类标识选中）
4. **加标签（必须 UI 操作）**：点「请搜索添加标签」→ 键盘输入「人工智能」→ 点 `li:has-text('人工智能')` → **验证弹窗内出现标签 chip**（服务端 API 写入的 tag_ids 弹窗不渲染，会报「至少添加一个标签」）
5. **发布**：点「确定并发布」→ 跳转 `/published` 即成功
6. **验证**：草稿详情接口返回 `article_id` → `https://juejin.cn/post/<article_id>`

## 接口契约补充（第二篇实测）

- `POST /content_api/v1/article/publish`：`{draft_id, sync_to_org:false, column_ids:[], theme_ids:[], encrypted_word_count, origin_word_count}`
- `POST /content_api/v1/article_draft/update` 的 `tag_ids` 必须是**字符串数组**（detail 接口返回数字，直接回传会报 unmarshal 错误）
- 分类 chips 在弹窗内为 `div.item.active`（选中态类名 `active`）

## 掘金真实接口契约（2026-08 实测）

| 接口 | 说明 |
|---|---|
| `POST /content_api/v1/article_draft/create` | 建草稿：`{category_id, tag_ids, link_url, cover_image, title, brief_content, edit_type:10, html_content:"deprecated", mark_content}` |
| `POST /content_api/v1/article_draft/update` | 更新草稿：同上 + `{id, is_gfw, is_english, is_original}` |
| `POST /content_api/v1/article_draft/detail` | `{draft_id}` → 返回含 `article_id` |
| `POST /content_api/v1/article_draft/query_list` | `{}` 草稿列表 |
| `POST /tag_api/v1/query_tag_list` | 标签搜索 |
| `POST /content_api/v1/article/query_list` | 文章列表 `{user_id, cursor, sort_type:2}` |

## 博客⑦踩坑记录（2026-08-17，重要！）

发布博客⑦时踩了三个坑，均为**接口契约**问题：

1. **`article_draft/create` 不保存 `mark_content`**（内容为空）
   → publish 报 `err_no 1010 文章内容为空`；且 UI 弹窗点「确定并发布」**不发任何请求**
   （前端校验内容为空静默拦截）。
   **解法**：create 之后必须再调 `article_draft/update` 写入 `mark_content` + `brief_content`。
2. **`article/publish` 请求体只有** `{draft_id, sync_to_org:false, column_ids:[], theme_ids:[], encrypted_word_count, origin_word_count}`——
   **分类和标签从草稿读取**，publish body 里传 `category_id`/`tag_ids` 会被静默忽略！
   → 文章以分类=0、无标签创建 → **页面 404（隐藏）**。
   之前博客①-⑥能成功是因为 UI 弹窗里**手动点选了分类**（服务端 API 写的分类弹窗不渲染）。
3. **账号发布限制 `err_no 1012`**（"账户目前受到限制，暂时无法发布文章"）：同日多次发布尝试会触发，
   历史上次日自动解除。**解除后恢复方案**：对已绑定隐藏文章的草稿（`7674870309702942735`，
   内容/分类/标签都已就绪）重跑 UI 发布流程（`juejin_publish_final.py <草稿URL>`），
   弹窗中手动点选分类「人工智能」→ 验证 chip → 确定并发布，即会**更新**该文章并补齐分类标签。

**可靠发布流程（修正版）**：
```
1) article_draft/create {title, mark_content}          → draft_id
2) article_draft/update {id, category_id, tag_ids:[字符串], brief_content, mark_content}
3) 打开 editor/drafts/{draft_id} → 点「发布」→ 弹窗内 UI 点选分类「人工智能」
   → 确认标签 chip → 点「确定并发布」
4) 验证 article_draft/detail 的 article_id → post URL 200（SSR 有延迟，等 2-3 分钟）
```
