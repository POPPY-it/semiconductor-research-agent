## 关键步骤备忘

1. **扫码登录**：`juejin_qr_login.py` 用空配置启动 Chrome → juejin.cn/login → 点「扫码登录」tab → 每 20s 刷新 `juejin_qr.png`，用户扫码后自动保存会话并退出
2. **建草稿**：`editor/drafts/new` → 标题 `input[placeholder*='标题']` → 正文用 `document.querySelector('.CodeMirror').CodeMirror.setValue(md)` 注入 → 等待自动保存（真实 create 请求）
3. **发布弹窗**：点「发布」→ 弹窗三个 byte-select 分别是 标签/专栏/话题；分类是平铺单选（点文本「人工智能」）
4. **加标签**：点「请搜索添加标签」文本 → `page.keyboard.type("人工智能")` → 点 `li:has-text('人工智能')`
5. **发布**：点「确定并发布」→ 页面跳转 `/notification/system` 即成功
6. **验证**：草稿详情接口返回 `article_id` → `https://juejin.cn/post/<article_id>`

## 掘金真实接口契约（2026-08 实测）

| 接口 | 说明 |
|---|---|
| `POST /content_api/v1/article_draft/create` | 建草稿：`{category_id, tag_ids, link_url, cover_image, title, brief_content, edit_type:10, html_content:"deprecated", mark_content}` |
| `POST /content_api/v1/article_draft/update` | 更新草稿：同上 + `{id, is_gfw, is_english, is_original}` |
| `POST /content_api/v1/article_draft/detail` | `{draft_id}` → 返回含 `article_id` |
| `POST /content_api/v1/article_draft/query_list` | `{}` 草稿列表 |
| `POST /tag_api/v1/query_tag_list` | 标签搜索 |
| `POST /content_api/v1/article/query_list` | 文章列表 `{user_id, cursor, sort_type:2}` |

## 环境要点

- Playwright + 本机 Chrome（`launch_persistent_context`），无需下载浏览器
- 所有脚本运行前需清空代理环境变量；Playwright 需沙箱放行（管道 + GUI 进程）
- 发布后：掘金进入审核流程，草稿箱清空、文章列表暂不可见，但文章 URL 已生效（200）
- 遗留注意：文章被误加了一个创作话题「人工智能创作者签约季」，可在编辑页移除
